Scene 04 The framework

T · C · D

Three things every good prompt carries. Miss one and the agent guesses. Guessing is where your afternoon goes.

Press ↓ to practice on real prompts.

T
Task
What, exactly, should change. One outcome, stated as a verb.
C
Context
Files, constraints, environment, and the things it must not touch.
D
Done signal
How the agent knows it succeeded — a command that passes, an output it can read.

Scene 05 The consequence

When the desk fills, the agent doesn't tell you what it forgot.
It just starts being wrong with confidence.

Symptom

It re-asks something you answered. It reverts a decision. It "forgets" a constraint from ten turns ago.

Cure

Short instructions. Skills loaded on demand. And a /clear before the desk collapses.

Concise instructions survive longer

Scene 07 Why this matters

01

Version it. Review it. Share it across the team like any other file.

Ten skills installed, zero cost until one is actually invoked.

Scene 09 The two-correction rule

Wrong◆
Correction◆
Still wrong◆
RESET · /clear■
Fresh prompt, better written◆

If two corrections haven't fixed it,
the third one won't either.

A third correction isn't more information. It's more noise on top of a prompt that was wrong from the start. Kill the session. Rewrite the prompt using T·C·D. You'll be done before you would have finished arguing.

Scene 10 Adding external context

Point at a file with @. The agent reads it from disk — not from your clipboard, not from your description of it.

@src/auth.ts

Drop a screenshot. Circle the broken thing. The agent now talks about your button, in your component, not a hypothetical one.

screenshot.png

Paste the docs URL. It cites the actual signature from the actual version — instead of the one it half-remembers from two years ago.

fetch docs

Pipe it. 40,000 lines of log that you will never scroll through, read in one gulp. Zero copy-paste.

cat server.log | claude

Scene 12 Hooks

Rules the agent
cannot talk its way out of.

A prompt is a request. A hook is a law. It runs your script at a lifecycle event, and it can say no.

  • Prevent editing protected files
  • Automatically run tests
  • Notify Slack after completion
